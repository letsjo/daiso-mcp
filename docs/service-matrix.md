# 서비스 지원 기능 매트릭스

작성일: 2026-03-07 (KST)

## 표기 기준

- `지원`: 현재 코드베이스에서 제공 중
- `부분 지원`: 공개 웹 기준 일부만 가능
- `계획`: 구현 우선순위는 정했지만 아직 코드 없음
- `보류`: 앱 트래픽 실측 또는 추가 검증이 먼저 필요

## 소매 서비스

| 서비스     | 상태 | 상품 검색 | 매장 탐색 | 가격 정보 | 재고 확인 | 비고                                         |
| :--------- | :--- | :-------- | :-------- | :-------- | :-------- | :------------------------------------------- |
| Daiso      | 지원 | 지원      | 지원      | 지원      | 지원      | 현재 가장 완성도 높은 소매 서비스            |
| Oliveyoung | 지원 | 부분 지원 | 지원      | 없음      | 지원      | 재고 조회는 상품 검색과 주변 매장 결합 방식  |
| Emart24    | 계획 | 계획      | 계획      | 없음      | 보류      | `goods`는 카탈로그 가능, 재고는 앱 실측 필요 |
| GS25       | 계획 | 부분 지원 | 계획      | 없음      | 보류      | 상품 API 흔적은 있으나 CSRF, 403 리스크 있음 |
| CU         | 계획 | 없음      | 계획      | 없음      | 보류      | 웹 기준으로는 매장 탐색만 구현 근거 확보     |
